# HWP 문항 문서 변환 자동화

반복적인 교육 문서 가공 작업을 줄이기 위해 만든 로컬 변환 프로그램입니다. HWP 문제·문항정보표·정답 및 해설과 과목별 Excel 메타데이터를 입력받아, 문항 업로드용 HML과 XLSX를 생성합니다.

이 저장소는 프로젝트를 소개하는 포트폴리오입니다. 운영 소스, 업무용 원본 자료, 메타데이터, 변환 결과와 실행 파일은 포함하지 않습니다.

## 해결한 문제

원본마다 문단 스타일, 문항 번호, 표와 수식의 배치가 달라 일괄 변환만으로는 누락을 막기 어려웠습니다. 사람이 매번 결과를 고치는 대신, 반복되는 예외를 파싱·정규화 규칙에 반영하고 결과를 검증하도록 구성했습니다.

## 주요 기능

- HWP 및 HWPX를 로컬에서 읽고 문제·정답·해설을 공통 모델로 정리
- 표·그림·수식을 포함한 HML과 업로드용 XLSX 생성
- 브라우저에서 분류표 편집, 토픽별 단원 자동 채움, 메타데이터 계산 미리보기
- 문항 수, 정답 누락, 수식 내용 등 최종 결과 검사
- Python 임베디드 런타임을 포함한 Windows 배포 패키지 구성

웹 업로드는 HWP 입력을 사용하며, HWPX 처리는 로컬 변환 모듈에서 지원합니다.

## 구조

```mermaid
flowchart LR
    A[문제·문항정보표·정답 및 해설] --> B[문서 파싱]
    B --> C[문항 모델 정규화]
    D[과목별 Excel 메타데이터] --> E[메타데이터 연결]
    C --> E
    E --> F[로컬 웹 검토·수정]
    F --> G[HML·XLSX 생성 및 검증]
    G --> H[결과 다운로드]
```

## 구현 과정에서 다룬 사례

### 원본 형식 예외 처리

글자가 없는 문단에도 표·그림·수식이 있을 수 있어, 텍스트가 비었다는 이유로 해설을 버리지 않도록 처리했습니다. 페이지 장식 제목은 위치와 내용을 함께 확인해 본문과 구분했습니다.

### 미리보기와 최종 Excel의 일관성

같은 단원도 기준 자료에 따라 번호 표기가 달라 코드 조회가 실패했습니다. 업로드한 Excel의 단원정보를 기준으로 자동 채움과 최종 계산을 맞추고, 하나의 토픽이 여러 단원에 대응하는 경우에는 임의 매칭을 피했습니다.

### 비동기 응답으로 인한 편집 손실 방지

미리보기 계산 중 사용자가 다시 수정하면 이전 계산 응답이 최신 입력을 덮어쓰는 문제가 있었습니다. 요청 번호, 작업 ID, 요청 당시 입력을 확인해 오래된 응답을 반영하지 않도록 수정하고 회귀 테스트를 추가했습니다.

## 검증

0.4.3 개선 과정에서 내부 예제 36세트·740문항을 교과별 Excel 메타데이터 10종으로 로컬 검증했습니다. Python 테스트 126개와 JavaScript 테스트 5개를 통과했고, 생명과학·통합과학 사례로 업로드부터 편집·미리보기·최종 다운로드까지 웹 흐름을 확인했습니다.

이 수치는 해당 테스트 자료와 검사 범위의 결과입니다. 모든 HWP 서식에 대한 호환성이나 한글 프로그램에서의 시각적 렌더링까지 보장하는 수치는 아닙니다.

## 사용 기술

Python, HWP 5.x OLE 파싱, XML/ZIP 기반 HWPX 처리, openpyxl, JavaScript, HTML/CSS, unittest, Node.js 테스트 러너.
